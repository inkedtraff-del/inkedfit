# RONIN — сайт

## Структура
```
index.html          страница
css/styles.css      все стили, две темы (Ink / Paper)
js/main.js          логика; всё, что меняется, лежит в CONFIG в начале файла
api/apply.js        заявки на ведение -> ваш Telegram
api/subscribe.js    email (гайд и лист ожидания) -> Kit
assets/guide        бесплатный PDF-гайд
assets/fonts        шрифты (Archivo, Cormorant), уже подключены
assets/images       сюда фото
assets/icons        фавикон
vercel.json         кеширование
```

## Что поменять в js/main.js (CONFIG)
- `brand` — сценическое имя. Логотип, шапка и футер подхватят его сами.
- `price` — цена текущего дропа (сейчас 27).
- `checkoutUrls` — ссылка Whop на каждый месяц (Cycle I уже подключён). Сайт сам
  открывает чекаут в тёмной или светлой теме, как у посетителя. В месяц N продукт в Whop должен
  содержать циклы 1..N: покупатель получает текущий цикл и все предыдущие.
- `rings` — пять циклов: название, описание, цвет, дата дропа `drop`.
  Сайт сам переключается на новый цикл в день дропа: меняются главный экран,
  карточка предложения, акцентный цвет кнопок, список «You get» и таймер.
- Проверить любой месяц заранее: добавьте к адресу `?today=2026-11-05`.
- `coaching.open` — сколько мест свободно. Меняйте вручную.

## Фото
Всё уже подключено. Положите файлы в `assets/images` с такими именами. Формат любой: AVIF, WebP, JPG, JPEG или PNG (кроме og.jpg, он только JPG):

| Файл | Что это | Размер |
|---|---|---|
| hero-dark | спина на тёмном фоне (главный экран) | 1080x1620, вертикально |
| hero-light | спина на светлом фоне (тема Paper) | 1080x1620, вертикально |
| pdf-1 | страница PDF: тренировочный день | скриншот с телефона |
| pdf-2 | страница PDF: план питания | скриншот с телефона |
| pdf-3 | страница PDF: расчёт калорий | скриншот с телефона |
| pdf-4 | страница PDF: список продуктов | скриншот с телефона |
| guide-cover | обложка бесплатного гайда | 3:4, вертикально |
| og.jpg | превью ссылки в соцсетях | 1200x630 |

Пока файла нет, на его месте видна заглушка. Если есть только hero-dark,
он показывается в обеих темах. Перед загрузкой сожмите фото на squoosh.app
(JPG, качество ~75), чтобы сайт открывался быстро.

## Отзывы
Блок есть, но скрыт (`hidden` у секции `.proof`). Уберите атрибут, когда будут настоящие.

## Запуск локально
`python3 -m http.server` в папке сайта, открыть http://localhost:8000.
Локально формы работают в демо-режиме и никуда не отправляют.

## Деплой на Vercel
1. Залить папку в GitHub, импортировать проект в Vercel (без настроек сборки).
2. Settings > Environment Variables:
   - `TELEGRAM_BOT_TOKEN` — создайте бота у @BotFather.
   - `TELEGRAM_CHAT_ID` — напишите боту /start, затем откройте
     https://api.telegram.org/bot<ТОКЕН>/getUpdates и возьмите `chat.id`.
   - `KIT_API_KEY`, `KIT_FORM_GUIDE`, `KIT_FORM_WAITLIST` (см. ниже).

## Email через Kit (бесплатно до 10 000 подписчиков)
1. Зарегистрируйтесь на kit.com.
2. Grow > Landing Pages & Forms > создайте две формы: «Guide» и «Waitlist».
   Откройте каждую: число в адресной строке — это её id.
3. Settings > Developer > создайте API key (v4).
4. Впишите ключ и два id в Vercel (Environment Variables) и сделайте Redeploy.

Как работает: человек вводит email, сайт сразу показывает кнопку «Download the guide»,
а email сохраняется в Kit. Когда выйдет новый цикл, делаете рассылку
(Send > Broadcasts) по всем подписчикам.

## Перед запуском
Ссылки Instagram и email в футере, страницы Terms и Privacy (для США и сбора email обязательны),
условия возврата в FAQ, длительность и частота тренировок в циклах, названия циклов IV и V.
